# Plataforma telemática para eventos deportivos masivos

## Descripción

Diseño, implementación y evaluación de una plataforma cloud-native end-to-end
para la adquisición, procesado en tiempo real y visualización de datos generados
durante eventos deportivos de alta intensidad, con un caso de uso inspirado en
la modalidad Hyrox.

## Estructura del repositorio

- `infra/` — Infraestructura como código: clúster, Helm charts, manifiestos
- `components/` — Microservicios: simulador IoT, procesador en streaming
- `experiments/` — Pruebas de carga, resultados y análisis
- `data/` — Datos de muestra (no incluidos por privacidad)
